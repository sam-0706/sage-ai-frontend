# SAGE web design direction

The web app uses a warm editorial workspace rather than a conventional SaaS dashboard. Dense black typography, an ivory canvas, electric violet, chartreuse and coral create a confident but restrained identity. The primary visual metaphor is a living route: goals, classes, people and opportunities are connected by thin plotted paths.

The public page opens with one sharp promise, a live-looking route canvas and one Google action. Inside the product, a compact rail keeps six destinations stable while each screen gives one dominant task. Dashboard metrics sit in an asymmetric field, jobs read like a curated opportunity desk, and the network view is a real interactive force graph.

Motion is short and functional: route lines draw in, panels settle by a few pixels, and loading states explain the current operation. Mobile uses a bottom dock and stacked content. All controls retain visible focus states and respect reduced motion.
